## Sobre mí
 
Soy desarrollador fullstack con foco en construir productos web completos: desde el modelado de datos y la API en el backend, hasta la interfaz que finalmente usa la gente. Trabajo principalmente con Java y Spring Boot para servicios backend, y con React y TypeScript para el frontend, aunque me muevo cómodo en otros stacks cuando el proyecto lo pide.
 
Me interesa especialmente la parte de diseño de sistemas: cómo estructurar una API para que escale sin volverse un caos, cómo organizar el estado de una aplicación frontend para que no se vuelva impredecible, y cómo balancear velocidad de entrega con código que alguien más pueda mantener seis meses después. No busco usar la tecnología más nueva por moda; busco la que resuelve el problema con menos fricción.
 
Vengo de [breve contexto: ej. "trabajar en proyectos freelance y un par de productos internos en equipos pequeños"], lo que me obligó a tocar todas las capas del desarrollo y a aprender a priorizar bajo recursos limitados.

## Cómo trabajo
 
Algunas cosas que he ido aprendiendo en proyectos reales, más allá de la lista de tecnologías:
 
- He colaborado con equipos multidisciplinarios (diseño, producto, backend) traduciendo requerimientos de negocio en tareas técnicas concretas, lo que me obligó a hacer buenas preguntas antes de escribir código.
- He tenido que tomar decisiones de arquitectura con información incompleta y ajustarlas después, en vez de esperar a tener el plan perfecto.
- He revisado código de otros desarrolladores y recibido revisiones del mío; prefiero el feedback directo a las reuniones largas.
- He trabajado bajo plazos ajustados sin perder de vista qué partes del código no se pueden apurar (seguridad, integridad de datos).
